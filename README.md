# Hazri

A phone web app for the Udaipur Regional Office. It creates a Google Meet VC, shares the link with the time, agenda and who is heading it, and shows which branches have joined, joined and left, or not joined yet, with one-tap calling for the ones missing.

- Plain HTML, CSS and JavaScript. No build step, no server, no database.
- Talks only to Google (sign-in and the Meet REST API) from the phone.
- Branch and staff data is imported on the phone from `udairo.js` and never stored in this repository.

Setup steps are in [SETUP.md](SETUP.md).
